# ÖZNET

ÖZNET, test numarası ve kontör durumunu izlemek için tasarlanmış bir web arayüzü başlangıcıdır.

## Yayınlama

Ana dalda yapılan her değişiklikte GitHub Actions, `web/` klasörünü GitHub Pages'e dağıtır. GitHub deposunda **Settings → Pages → Source** seçeneğini **GitHub Actions** olarak ayarlayın.

Yerelde önizlemek için `web/index.html` dosyasını bir tarayıcıda açın.
